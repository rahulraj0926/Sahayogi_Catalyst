# handoff: hand over to developers
**Prototype source:** `handoff.js`. **API:** `GET /api/handoff/overview`, `GET /api/handoff/preview?story=`, `POST /api/handoff/create {story}`, `POST /api/handoff/deliver {story}`, `GET /api/handoff/receiver`.
**Env:** `HANDOFF_RECEIVER_URL` on the API enables "Send to developer tool" (see `docs/PROTOTYPE_README.md`).
