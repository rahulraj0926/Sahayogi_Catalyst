# existing: existing system (replace / rebuild products)
**Prototype source:** `existing.js`. **API:** `GET /api/existing`, `POST /api/existing/:id/confirm`, `POST /api/existing/:id/feature`, `POST|PATCH /api/items` (type `SystemFunction`).
Only shown for products whose mode is `existing_system` (the registry shows it always; the page explains when it does not apply).
