# checks: things to check (second-person verification)
**Prototype source:** `cw_checks.js`. **API:** `GET /api/agent/queue`, `GET /api/agent/checked`, `POST /api/agent/verify/:id {note}`, `POST /api/agent/reject/:id {note}`.
**Rule kept:** whoever typed a value in, or asked the assistant for it, cannot check it.
**Not yet ported:** "check everything that is mine to check" one-note bulk button.
