# Feature map

Every screen is one folder in `apps/web/features/<id>/` (an `index.tsx` and a `README.md`) plus one line in `apps/web/features/registry.ts`. The URL is `/p/<product>/<id>/...`.

**Add a feature:** make `features/<id>/index.tsx` (default export, takes `{pid,args,query}`), copy a README, add one registry line.
**Alter a feature:** edit only its folder. **Remove a feature:** delete its registry line (and the folder).
**Claude Code prompt:** "Read apps/web/features/<id>/README.md and the prototype source it names, then finish the 'Not yet ported' list."

Status: every screen renders against the live API and was checked in a browser (no console or API errors). "Not yet ported" lists the finer prototype details still missing. See `docs/AUDIT.md` for the prototype-to-platform audit.
